# Editable game model

`ck_character_fit` contains the final MLOD and matching configuration/materials used to build the adjacent PBO. Keep the `ck_character_fit` prefix and `ck_uniform` model class together. Materials refer to the addon prefix and procedural fit-test colors.

The model can be inspected in Arma Object Builder. Building requires the installed Arma 3 Tools and the usual Arma 3 configuration/material dependencies. On the original workstation, builds use the shared Binarize lane in `D:/Codex/Mapmaking_Omnibus_Production/build/binarize_lane.py`; the verified build scripts and complete source scene are retained in `D:/CharacterKit/codex/studies/arma_fit_v2/`.

This source includes the fitted game model, not the original purchased sculpt archives or official animation reference files. Production support LODs and texture work are still pending as described in the package README.
