# B2 integration tests

Use the two exact PBOs identified in build.json with the usual Aux dependencies and installed external WebKnight mod. The VR fixture has four HC slots and dispatches tests to the dedicated server plus each HC owner. Select guards.sqf or run.sqf in init.sqf. The comparison runs for 120 seconds and uses invulnerable stationary targets; it is not a playable mission.

Summaries retain individual assertions and formation/firing metrics. The local Runtime-Evidence.zip retains raw RPTs, including unsuccessful earlier trials. No external WebKnight source is bundled.
